# Project assets

This folder collects the material used to explore, document and support the project’s retro computing environments. It includes guest utilities, example applications, disk images, ROM reference collections, user guides and illustrations.

Start with the relevant system folder: [CP/M-80](cpm80/README.md), [CP/M-86](cpm86/README.md), [Apple II](apple2/README.md) or [UCSD Pascal](ucsd/README.md). The [shared CP/M collection](cpm/README.md), [Apple download collection](apple2Downloads/README.md), [user guides](readMes/README.md) and [images](images/README.md) serve separate reference and documentation purposes.

The presence of an archived disk or ROM here does not by itself establish that the emulator supports it.

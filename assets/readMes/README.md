# System user guides

This folder collects the user-facing guides for the retro environments offered by the project. It helps readers understand what each system provides, how to begin using it and which limitations apply.

Choose the guide for [CP/M-80](README_CPM80.md), [CP/M-86](README_CPM86.md), [Apple II](README_APPLE2.md), [UCSD Pascal](README_UCSD.md) or [SWTPC 6800](README_SWTPC.md). These guides complement the [main project overview](../../README.md).

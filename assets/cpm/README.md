# Shared CP/M reference collection

This folder collects historical CP/M software, archives and disk-related reference material. It provides a shared collection alongside the project-specific utility folders for CP/M-80 and CP/M-86.

Expect separate disk-image collections for the two systems, a WordStar package and material for inspecting disk formats. Software in this collection may target different machines; its presence does not establish compatibility with the project.

# CP/M-80 assets

This folder brings together the utilities and supporting material for working in the CP/M-80 environment. It is the starting point for readers looking for tools to edit text, browse files, read help, inspect the emulated system or compare its performance.

The subfolders group each utility with its related material. For an introduction to the environment, see the [CP/M-80 guide](../readMes/README_CPM80.md).

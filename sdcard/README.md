# SD-card working layout

This folder is the project-local workspace for preparing the directory layout and disk images intended for the device’s microSD card. Use it to organise card content on the desktop before copying it to an already formatted card.

Keep the relative paths beneath this folder when transferring the layout to the card root. Preparing the layout does not format the card or automatically make every disk available to an emulator; guest drive assignments are controlled by the relevant firmware configuration. See the [Retro folder](retro/README.md) for the distinction between working disks and recovery copies.

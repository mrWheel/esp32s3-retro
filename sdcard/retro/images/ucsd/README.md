# UCSD Pascal / Apple Pascal working disks

This folder provides persistent virtual-disk storage for the UCSD Pascal / Apple Pascal environment on the microSD card. Use it for the guest volumes on which you want to keep applications, documents and ongoing work between sessions.

Place compatible images directly in this folder and map them through the environment’s firmware drive configuration. The mapping determines which guest drive opens an image and whether it is read-only or writable. Use File Transfer or the project’s disk-image tools to manage guest contents; keep recovery copies separate from these working disks.

# Manual recovery copies

This folder keeps recovery copies separate from the working disks used by the emulators. Use it to preserve a known state before changing disk contents or experimenting with a configuration.

The system-specific subfolders organise copies for manual recovery. Nothing here establishes an automatic backup schedule or guarantees that a copy is current. Restore deliberately by copying the selected material back to its intended working location after stopping disk activity.

This collection is named `backups`; it is separate from the `backup` directory created by the card-preparation tool for the standard card layout.

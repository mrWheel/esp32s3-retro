# CP/M-80 recovery copies

This folder keeps manually retained recovery material for the CP/M-80 environment. Its purpose is to preserve a reference state separately from the disks used for everyday guest work.

Use it when saving a known setup before changes or recovering from an unwanted modification. Stop guest disk activity before restoring, copy the selected material to its intended working location, and check that the active drive configuration points to that location. Keeping a copy here neither mounts it nor updates it automatically.

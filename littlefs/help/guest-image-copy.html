Purpose

Copy single files from one disk image to another, entirely on the SD card.

Steps

  1. Choose the source OS, image and user area, then press Choose files… and tick the files to copy.
  2. Choose the destination OS, image and user area.
  3. Tick OVERWRITE only if existing files may be replaced (confirmation required); otherwise existing names are skipped.
  4. Press the copy button.

Details

  • The source can be the same image as the destination, for example to copy files to another CP/M user area. The source is never changed.
  • Copies between different systems are allowed, for example CP/M-80 to CP/M-86, or ProDOS to UCSD Pascal. File type and Pascal kind are mapped; DOS 3.3 headers are removed on reading and rebuilt on writing.
  • ProDOS subdirectories are listed but cannot be opened.
  • Files stream in small chunks, so large files are fine. Writes are journaled like in Computer → SD.

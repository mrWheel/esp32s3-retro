Purpose

Download single files from inside a disk image to your computer.

Steps

  1. Choose the OS, the disk image and optionally a user area filter.
  2. Press Choose files… and tick one or more files. The line below the button shows how many are selected.
  3. Press the download button.

Details

  • One file is downloaded as it is.
  • Several files are packed into one ZIP file by default, so the browser asks where to save only once. Untick the ZIP option to download them separately.
  • Damaged files (broken extent chains) are shown but cannot be downloaded.
  • The image is never changed.

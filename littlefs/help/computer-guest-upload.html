Purpose

Put single files from your computer inside an existing disk image on the SD card.

Steps

  1. Choose the OS, the disk image and, for CP/M, the user area (the selector is hidden for file systems without user areas).
  2. Add files by selecting them or by dragging them (or a folder; only its top-level files are used) onto the drop zone.
  3. Check the Preview: it shows the name each file gets in the image, flags invalid or duplicate names and shows which names already exist. Use Remove or Clear list to correct it.
  4. Tick OVERWRITE only if existing files may be replaced (confirmation required).
  5. Press Copy. Nothing is stored before this.

Details

  • Names are converted to the rule of the destination file system, in uppercase (8.3 for CP/M).
  • A source file named NAME#ADDR.BIN (ADDR is 1-4 hex digits) is stored as NAME (without extension) with file type BINARY (06) and load address ADDR; the typed Apple file type and Aux type / load address fields win when they are filled.
  • Empty files cannot be stored. Overwriting needs free room for the old and the new copy at the same time.
  • Data goes to free blocks first and the directory is updated last through an undo journal, so a power loss leaves either the old or the new state, never a half file.
  • The list of files already in the image can be opened under “Files already in this image”.

Purpose

Copy complete disk images from your computer to the SD card, or replace the drive configuration drives.cfg of one OS.

Steps

  1. Choose the Destination OS directory. Images are always written to /retro/images/<OS>/ on the SD card; the target is shown next to the selection.
  2. Choose Copy From: “Disk images” or “drives.cfg”.
  3. For disk images, drag image files or a folder from Finder / File Explorer onto the drop zone. No file picker is provided.
  4. Check the Preview list. It shows for every file the full destination on the SD card and its result: new, will be skipped, will be overwritten or rejected. Use Remove or Clear list to correct the list.
  5. Tick OVERWRITE only if existing images may be replaced (you must confirm). Without it, existing images are skipped.
  6. Press Copy disk image(s) to SD. Nothing is copied before this moment.

Details

  • When you drop a folder, only its top-level files are used; subfolders are ignored and reported.
  • Replacing an image that is mapped in drives.cfg affects the image the next time the emulator starts.
  • For drives.cfg: choose the file on your computer (any file name). It is stored in LittleFS as /littlefs/<OS>/drives.cfg after confirmation. A failed upload leaves the old file unchanged.

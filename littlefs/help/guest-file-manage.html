Purpose

Rename or delete single files inside a disk image.

Steps

  1. Choose the OS, image and user area, then press Choose files….
  2. Delete: tick one or more files and press Delete; you must confirm.
  3. Rename: tick exactly one file, type the new name and press Rename.

Details

  • Delete frees the directory entries only. The data blocks become free space.
  • Rename refuses a name that already exists and keeps the user area.
  • Both actions are journaled: an interrupted operation is rolled back the next time the manager touches that OS directory.

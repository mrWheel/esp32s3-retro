Purpose

Browse the image files of one OS on the SD card and manage them.

Steps

  1. Choose the OS directory. The list shows the files in /retro/images/<OS>/ (there are no sub-directories), their size and their drive mapping.
  2. Use the buttons on a row to download, copy, rename or delete the file.
  3. Tick OVERWRITE on image copy if a copy may replace an existing file.
  4. Restore preserved image backup brings back the version of an image that was preserved when it was overwritten.

Details

  • Actions are allowed regardless of the RO/RW mapping in drives.cfg.
  • Deleting or renaming a mapped image can break a drive reference. Read the warning and confirm deliberately.
  • drives.cfg can be replaced only through Computer → SD; drives.cfg cannot be deleted here.

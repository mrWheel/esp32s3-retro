Purpose

Make a copy of a complete disk image on the SD card, for example as a backup or as a starting point for a new disk.

Steps

  1. Choose the source OS and the source image.
  2. Choose the destination OS and type the new image file name (a name only, no directory).
  3. Tick OVERWRITE only if an existing destination may be replaced (confirmation required).
  4. Press Copy complete image.

Details

  • The firmware copies in small chunks and verifies the bytes before the new file is committed. The source stays unchanged.
  • When overwriting, the previous destination is preserved until the commit succeeds.
  • A drive marked RO in drives.cfg can still be a source or destination; drives.cfg itself is not rewritten.
  • This creates a new image file. To copy single files into an existing image use SD → SD → Files between disk images.

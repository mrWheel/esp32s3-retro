What is this?

Retro Disk Manager lets you work with the disk images on the SD card of the ESP32 retro computer from your web browser. You do not need any extra program on your Mac, Windows or Linux computer, and no emulator has to be running.

The menu bar

  • Computer → SD: bring things from your computer onto the SD card, either complete disk images or single files that are placed inside a disk image.
  • SD → Computer: take things from the SD card to your computer, either complete disk images or single files from inside a disk image.
  • SD → SD: copy inside the SD card, either whole disk images or single files from one disk image to another.
  • Manage: browse the images on the SD card, copy, rename or delete them, and rename or delete single files inside a disk image.
  • Help: this text. Every function has its own Help with more detail.

Click a menu title to open the menu, then click an item. Items that are greyed out are not implemented yet. When a function is open, the menu bar shows its name, Back to Main and Help.

Terms

  • Disk image: one file on the SD card (for example .dsk, .po, .img) that contains a complete floppy disk of an emulated machine. Images live in /retro/images/<OS>/ on the SD card.
  • Guest file: a single file inside a disk image, as the emulated computer sees it.
  • OS: the emulated machine: CP/M-80, CP/M-86, UCSD Pascal, Apple II or SWTPC 6800. Each has its own image directory.
  • drives.cfg: the file per OS (stored in LittleFS as /littlefs/<OS>/drives.cfg, next to the system disk) that tells the emulator which image is in which drive (RO or RW).

Supported file systems

Single files can be listed, copied, renamed and deleted inside CP/M-80, CP/M-86, Apple II (ProDOS and DOS 3.3) and UCSD Pascal images (140K, 640K and 800K Apple images, either sector order). SWTPC 6800 is not yet supported for single files; whole images work for every OS.

Good to know

  • This manager runs only from the Retro menu system, and the web server cannot be started while an emulator is active. So no emulator can have an image open while you change it; the changed images are used the next time you start an emulator.
  • Every image can be managed, whether its drive is marked RO or RW in drives.cfg. Actions that could break a drive mapping show a warning and ask for confirmation.
  • drives.cfg can only be replaced through Computer → SD (Copy From = drives.cfg). It is stored in LittleFS.
  • The browser, not this page, decides where downloads are saved. Enable “Ask where to save each file” in your browser if you want a save dialog.
  • FAT32 on the SD card limits one file to less than 4 GiB.
  • Progress and results of an action are shown below the form.

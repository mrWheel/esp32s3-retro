Purpose

Download a complete disk image from the SD card or LittleFS, or download drives.cfg, to your computer.

Steps

  1. Choose the Source OS directory. No OS is preselected.
  2. The image list then shows disk images on the SD card and image files found in that OS's LittleFS directory (for example, system.dsk or system.po), using their actual filenames. drives.cfg is also available.
  3. Press Download selected item.

Details

  • The complete image container is downloaded byte for byte; this is not a download of the guest files inside it (use SD → Computer → Files from a disk image for that).
  • LittleFS images are available for download only as complete images. Use the guest-file workflows to read or write individual files inside them.
  • Browsers with the secure File System Access save picker ask for the destination when you start. Other browsers use their normal download behavior; enable “Ask where to save each file” in the browser settings if you want a destination picker.
  • Large images take a while; the progress bar shows the transfer.

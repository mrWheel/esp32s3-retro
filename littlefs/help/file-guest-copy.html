Purpose

Move ordinary files (not disk images) between the SD card directory of an OS and a disk image.

Top part: SD file → disk image

  1. Choose the OS and the ordinary file in /retro/images/<OS>/.
  2. Choose the destination image and user area, then copy. The guest name is converted to the rule of the file system (8.3 for CP/M).

Bottom part: disk image → SD file

  1. Choose the image, press Choose files… and tick the guest files.
  2. Copy them out. They are stored as ordinary files in /retro/images/<OS>/.

Details

  • An SD file is written to a temporary file and committed atomically. An existing SD file is replaced only after confirmation.
  • Names with characters such as $ are rejected because FAT file names do not allow them.
